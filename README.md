# 104 台灣 50 / 中型 100 管院頂尖實習雷達 (PWA)

> **課程專案**：國立大學產品管理與專案管理課程（PMCS）期末專案（Term Project）  
> **規格標準**：完全遵循羅士敏老師之產品需求文件（PRD v2 規格）  
> **視覺規範**：嚴格無 Emoji（Zero-Emoji）、高密度專業資訊架構、Merriweather 經典襯線字體、國立大學深綠配色（`#004030`）與暖金標籤（`#D8C3A5`）

---

## 1. 專案背景與痛點轉換（Persona Pivot）

原 PRD 規格聚焦於全職初階 PM/PjM 職缺。但在實際求職市場中，大學部與研究所管院同學（企管、資管、工管、財金、國企、行銷）面臨更迫切的挑戰：
1. **資訊不對稱**：想進台灣 50 或中型 100 指標大廠實習，但各家 JD 寫得含糊其詞，不清楚實際「每天要幹嘛」。
2. **修課方向迷惘**：不知道大學在學期間該先修什麼課（例如到底該修《資料庫管理》還是《統計學》）才能通過履歷審核。
3. **論壇避雷需求**：實習生最怕遇到打雜、行政黑手或部門風氣不佳，迫切需要一鍵連結 Dcard 與 PTT 的真實學生評價。

本系統即為解決上述痛點而生，每日定時觀測 104 人力銀行之**台灣 50（0050）與中型 100（0051）成分股企業**的管院實習機會，並透過 Google Gemini 自動萃取五大核心資訊。

---

## 2. 卡片五大核心資訊架構（免點擊直接呈現）

每張職缺卡片均在第一層直接呈現學生最在意的 5 大要素：

1. **地點（Location）**：廠區位置與捷運站距離。
2. **待遇（Salary）**：時薪制／月薪制說明。
3. **實際工作職責（Duties）**：AI 萃取之 3 點高密度條列說明，絕不灌水。
4. **建議先修大學課程（Courses）**：直接對應大學正式課程名稱（如 `[ 資料庫管理與 SQL ]`、`[ 統計學與數據分析 ]`），**點擊課程標籤可立即全站過濾**。
5. **論壇避雷與風評（Forum Links）**：一鍵跳轉 Dcard 工作板／實習板與 PTT Soft_Job/Tech_Job 搜尋評價，並附 104 官方原始連結。

## 3. 系統功能特色

- **內容優先首頁**：進站立即看到最新職缺卡片，不需填問卷即可探索。
- **即時多維篩選**：支援搜尋、公司等級（台灣 50／中型 100）、實習領域（資安IT／供應鏈採購／品牌行銷／商業數據／人資行政）、學歷要求與英文門檻。
- **3 秒能力自評與適配度**：
  - 內建三大典型角色一鍵代入：`行銷企劃型`、`商業數據型`、`專案運籌型`。
  - 即時計算各職缺契合度（%）並由高至低重新排序。
  - 所有自評資料皆存放於瀏覽器本機端（LocalStorage），零個人隱私外洩。
- **趨勢觀察儀表板（Insights）**：自動統計 Top 5 大廠最看重的先修大學課程與薪資地點分佈。
- **安全 CSV 匯出**：內建 UTF-8 BOM（Excel 開啟不亂碼）與公式注入防護（防止 `=cmd|` 安全弱點）。
- **離線 PWA 支援**：內建 Service Worker 與 Manifest，支援手機與桌面免安裝安裝為 App。

## 4. 爬蟲合規與資安原則（遵循 PRD 規格）

- **著作權保護（PRD 2.2 節第 5 點）**：系統嚴禁儲存 104 原始工作說明全文，只保留結構化標籤、AI 摘要與官方連結。
- **就業服務法合規（PRD 8.1 節）**：自動掃描性別、年齡、外貌、役畢等歧視性關鍵字，記錄於合規代碼並自評分中剃除。
- **狀態流轉與防誤判（PRD 2.4 節）**：未出現在列表之職缺記錄 `miss_count + 1`，**連續 3 天未出現才判定為 `closed`**。超過 30 天自動移入年度歷史封存。
- **金鑰隔離**：API 金鑰僅存於 `.env` 本機環境與 GitHub Secrets，絕不上傳公開倉儲。

## 5. 快速操作指南（免複雜安裝）

### 步驟一：啟動本機網頁預覽
在專案根目錄下，使用 Python 內建伺服器即可直接啟動：
```bash
python -m http.server 3000
```
開啟瀏覽器前往：`http://localhost:3000` 即可體驗完整功能。

### 步驟二：執行管線單元測試（驗證驗收標準）
為滿足老師審查作業需求，已內建自動化單元測試套件：
```bash
python scripts/pipeline.py --test
```
執行後將自動依序驗證：
- `[TEST 1]` 公司白名單比對與實習職稱過濾邏輯
- `[TEST 2]` 語意分析、先修課程萃取、Dcard 連結生成與就服法防歧視檢查
- `[TEST 3]` 狀態流轉機（連續 3 天 miss 下架緩衝判定與歷史封存）

### 步驟三：即時抓取並解析單一 104 職缺
若要在終端機示範爬取真實 104 職缺：
```bash
python scripts/pipeline.py --ingest <104職缺代碼>
```
